# 초안 D — 픽셀 대화 어드벤처 (축: 공간 속 인물 배치)

- 그림체: 16비트 픽셀아트, 따뜻한 오후 햇살(주황 빛, 보라 그림자), 한정된 색.
- 화면 문법: 교실 + 탕비실이 이어진 넓은 측면 고정 장면에 용의자 4명이 각자 자리에 있음. 인물이나 사물을 눌러 행동.
- 질문: 하단 동사 줄 [살펴보기 / 질문 / 증거]. [질문]을 누르면 레트로 대사창이 편집 상태가 되고 커서와 "직접 입력" 안내. 확정하면 초상 + 답변 상태로 교체. 한글은 읽기 쉬운 픽셀 글꼴.
- 현장 조사: 커서 모양만 바뀜(손 → 돋보기). 표식 없음.
- 추리 정리: 픽셀 수첩 메뉴, 진술 카드를 시간 줄에 끼움. "내 메모" 표시.
- 레퍼런스(문법만): Unavowed(장면 속 인물·사물을 눌러 행동), Coffee Talk·VA-11 Hall-A(고정 화면 대화 중심).
