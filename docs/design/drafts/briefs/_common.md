# 공통 조건 (모든 초안)

## 사건과 인물 (4개 초안 모두 동일)
- 사건: 학원 탕비실 냉장고에서 매니저님의 파란 뚜껑 도시락(제육볶음)이 사라졌다. 가볍고 웃긴 일상 미스터리.
- 장소: 학원 교실(책상, 칠판, 창문, 벽시계) + 붙어 있는 탕비실(냉장고, 전자레인지, 싱크대).
- 용의자 (오리지널 캐릭터, 20대 초반 학원생):
  - A: 짧은 검은 머리, 남색 후드티, 순해 보이지만 당황하면 눈을 피함
  - B: 갈색 포니테일, 운동복, 입가에 빨간 소스가 살짝 묻어 있음
  - C: 둥근 안경, 카디건, 노트북을 끼고 있음
  - D: 외투를 입은 채, 무심한 표정

## 반드시 지킬 것 (팀 피드백)
1. 화면 전체가 게임 그림. 웹 패널, 탭, 카드 그리드, 대시보드 같은 UI 금지.
2. 대화는 한 번에 한 대사. 채팅 말풍선이 쌓이는 목록 금지.
3. 현장에 ?, !, 반짝이 같은 조사 표식이나 조사 대상 목록 금지.
4. 시간·남은 질문 수는 작게, 가능하면 화면 속 사물로 표현.
5. 실존 게임의 캐릭터, 로고, 화면 구성을 복제하지 않는다. 장르 문법만 빌린다.

## 이미지 공통 규격
- 3:2 가로 게임 스크린샷, 1536×1024 (이미지 도구가 지원하는 가로 크기).
- 화면 속 글자는 짧은 한국어 라벨만 (긴 문장은 깨지기 쉬움).

## 초안마다 같은 4장면 (세션 4 합의)
1. 질문 작성: 플레이어가 자유 텍스트로 질문을 쓰는 중. 증거 하나 동봉 가능, 200자 제한, "묻기 · 1회" 확정 버튼. 쌓이는 문답 목록 없음.
2. 답변·반응: 확정한 질문 자리를 용의자 답변 한 발화(2~4문장)가 차지. 증거를 내밀었을 때의 반응.
3. 현장 조사: 표식 없음. 장면 구도와 생활 흔적으로 관심 유도, 무관한 사물도 눌러 보면 짧게 반응.
4. 추리 정리: 플레이어 메모로 명시된 가설(시스템 판정 아님).

## 초안별 비교 축
- A = 배우(용의자)의 반응
- B = 책상 위 증거 조작
- C = 기록과 대조
- D = 공간 속 인물 배치와 탐색

질문 수는 "질문 3/20"처럼 사용 수를 작고 선명하게 표시한다.
