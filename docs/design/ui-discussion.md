## 세션 1 — Codex 리뷰 (원문)

초안의 **‘한 장의 액자 속 현장’ 방향에는 동의**합니다. 다만 육성 시뮬레이션의 스탯 문법보다, **증거와 진술을 비교하고 질문 소비를 판단하는 흐름**이 우선입니다. 아래는 두 문서를 기준으로 한 설계 리뷰이며, 실제 화면 검증 전 제안입니다.

### 1. 추리게임 루프에 맞는가? 빠진 화면·정보는?

장면 클릭으로 조사하고, 인물을 눌러 심문하는 매핑은 6.7절과 잘 맞습니다. 다만 조사→심문→추리를 고정 단계로 표현하면 안 됩니다. 플레이어는 현장과 여러 용의자의 진술을 반복해서 오가야 합니다.

**우측 스탯 패널에 핵심 자원을 모으는 안은 수정**하겠습니다. 6.7절대로 남은 질문과 시간을 상단에 상시 표시하고, 우측은 증거 수첩이나 현재 용의자의 문답 기록을 보는 보조 영역으로 쓰는 편이 유용합니다. 증거는 수집률보다 내용 재확인이 중요합니다.

빠진 항목은 다음과 같습니다.

- 로비·대기실, 최종 추리 작성·제출 확인, 제출 후 대기 화면.
- 용의자별 이전 문답, 선택한 증거의 내용·첨부 해제, 질문 `0/200자` 표시.
- 최종 추리의 ‘아무도 아님’, 경위, 발견한 결정적 증거, 이유 입력. **제출은 1회이며 이후 조사가 끝남**을 확인창에 명시.
- 다른 플레이어는 닉네임·사용 질문 수·제출 여부만 표시. 정답은 게임 종료까지 비공개.
- 보고서는 진상·순위 외에 개인별 추리·단서·전체 문답과 인쇄용 구성이 필요합니다.

단서마다 모달을 여는 방식도 반복 조사를 끊습니다. 첫 발견은 카드로 보여 주되, 이후에는 수첩에서 바로 재열람하게 제안합니다.

### 2. 360px 폰에서 어떻게 접을 것인가?

**‘세로 스택’에는 반대**합니다. 장면·스탯·대사창을 모두 쌓으면 입력창과 단서를 번갈아 찾느라 스크롤이 길어집니다. 스펙의 모바일 우선 원칙에 맞춰 **작업별 단일 화면**으로 접겠습니다.

- 상단: `남은 시간 · 일반 질문 잔여` 고정. 다른 플레이어 진행은 펼침 패널로 이동.
- 하단: `조사 / 심문 / 수첩 / 최종추리`를 글자 라벨과 함께 배치.
- 조사: 배경 전체를 유지하고, 작은 핫스팟은 ‘조사 대상 목록’으로도 접근. 단서 내용은 발견 전 노출하지 않음.
- 심문: 장면 대신 작은 초상화·이름, 스크롤 가능한 문답, 입력창을 표시. 키보드가 열리면 하단 내비게이션을 접고 입력창을 키보드 위에 유지.
- 증거 선택: 전체 화면 목록에서 고른 뒤 심문으로 복귀. 질문 초안·첨부·스크롤 위치 보존.

### 3. 질문 수에 긴장감을 주는 표현은?

**체력처럼 줄어드는 막대만 사용하는 안에는 반대**합니다. 질문 잔여량과 승패에 쓰이는 누적 질문 수는 의미가 다릅니다.

주 표시는 **`일반 질문 12/20 남음`**, 보조 표시는 **`순위 계산용 총 질문 8회`**로 구분합니다. 작은 20칸 눈금은 보조 장식으로만 쓰고, 전송 버튼은 `질문하기 · 1회 사용`으로 표시합니다. 조사에는 `질문 소모 없음`, 증거 첨부에는 `추가 소모 없음`을 안내합니다.

집중 심문은 별도 자원입니다. 시작 전에 **대상 고정·1회 한정·최대 5회·순위에 합산**을 알리고, 진행 중에는 `집중 4/5 남음 · 01:32`와 전체 남은 시간을 함께 보여 줍니다. 전체 시간이 먼저 끝나면 종료된다는 안내도 필요합니다.

잔여 5회·1회에서 숫자와 문구로 경고하되, 전송마다 확인창을 띄우지는 않습니다. 응답 대기 중에는 중복 전송을 막고, **성공 후 차감**, 실패 시 초안 유지와 ‘질문이 차감되지 않았습니다’를 표시합니다.

### 4. 접근성·가독성 리스크는?

금색은 양피지 위 본문색으로 부적합합니다. **금색은 테두리·장식에 제한**하고, 본문은 짙은 남색을 쓰겠습니다. 와인색 경고도 색만으로 전달하지 말고 아이콘·문구를 병기해야 합니다.

본문은 Pretendard 또는 Noto Sans KR, 모바일 기준 16px·행간 1.6부터 검토합니다. Gowun Batang은 짧은 제목에 한정하고, **타이머·질문 수의 Galmuri 사용은 반대**합니다. 빠르게 읽어야 하는 숫자는 본문 계열의 고정폭 숫자가 적합합니다.

hover 전용 핫스팟에는 상시 표식·키보드 포커스·이름을 추가하고, 터치 영역은 44px 이상으로 제안합니다. 타자 효과는 끌 수 있게 하며 보조기기에는 완성된 답변을 한 번만 알립니다. 한글 조합 중 Enter 전송과 입력 중 숫자 단축키도 방지해야 합니다.

### 합의 제안

- 레이아웃: 현장 액자 유지, 상단에 시간·질문 고정, 데스크톱 보조 영역은 수첩·문답에 사용.
- 모바일: 세로 적층 대신 작업별 화면 전환, 입력·첨부·스크롤 상태 보존.
- 조사: 핫스팟과 동등한 조사 대상 목록 제공.
- 자원: 일반 잔여·집중 잔여·순위용 총 질문 수를 구분.
- 집중 심문: 대상 고정·1회 한정·시간 제한·순위 합산을 시작 전에 고지.
- 색: 금색은 장식, 남색은 본문, 경고는 색과 문구 병행.
- 폰트: 명조는 제목만, 본문과 핵심 숫자는 읽기 쉬운 산세리프.
- 그래픽: 장르의 배치 문법만 참고하고 캐릭터·로고·그림은 독자 제작.

## 세션 2 — 구현 검증 (스크린샷 6장 기반 Codex 리뷰)

Codex 지적과 처리 결과:

| 우선순위 | 지적 | 처리 |
|---|---|---|
| 1 | 폰에서 스크롤하면 시간·질문 표시가 사라짐 | `.game`을 `100dvh` 3행 그리드로 바꿔 상단 상태 바와 하단 탭을 고정하고 가운데 작업 영역만 스크롤 |
| 2 | 심문 기록이 쌓이면 입력창이 밀려남 | 심문 패널을 탭 / 기록(유일한 스크롤 영역) / 입력부로 분리. 폰 말풍선 16px |
| 3 | 탭을 오가면 최종 추리 작성 내용이 초기화됨 | `AccuseDraft`를 `GameScreen`으로 올림. 폰에서 모달은 하단 시트 형태의 전체 폭 |
| 4 | 폰에서 순위용 총 질문이 안 보임, 터치 영역 44px 미달 | 탐정 펼침 패널 맨 위에 "내 순위용 총 질문" 표시. 칩과 인물 버튼 최소 44px |
| 5 | 모든 액자가 같은 강도라 현장의 위계가 약함 | 보조 패널과 비활성 커맨드의 테두리·그림자를 약하게, 심문 중 현장 암막 0.35→0.15 |

**Claude가 유지하기로 한 것:** 데스크톱에서 최신 답변이 하단 대사창과 우측 기록에 함께 나오는 점. 하단은 "지금 말하는 장면"(초상 표정 + 타자 효과), 우측은 "다시 읽는 기록"으로 역할이 다르고, 대사창은 이 장르 레이아웃의 핵심이라 남긴다. 플레이 테스트에서 산만하다는 의견이 나오면 우측 기록의 마지막 답변을 타자 효과가 끝난 뒤에 붙이는 방식으로 바꾼다.

**다음 세션 후보:** 로비 연출 강화, 실제 아바타·배경 교체 후 색 대비 재검증, 실기기 키보드(VisualViewport) 대응.

## 방향 전환 (2026-11-18)

팀 피드백: 프린세스메이커풍 액자 화면은 의도와 달랐다. **고정 화면 2D + AI 용의자와의 대화를 통한 추리**가 핵심이다. 캐릭터 이동(탑다운)도 원하지 않는다.

새 설계 (Claude):
- 기본 화면 = 대화. 큰 초상(표정에 따라 배경색과 흔들림), 문답 기록, 질문 입력
- 답변의 문장을 눌러 📌 진술 카드로 고정 → 수첩(진술 / 증거 / 시간표 / 개요)
- 카드 두 장을 묶어 ⚡ 모순 가설로 만든다. 판단은 플레이어가 하고, 자동으로 판정하지 않는다
- 추궁 수단: 📎 증거 내밀기(효과는 코드가 판정, 스펙 그대로), ❝ 진술 인용(최대 2장)
- 현장은 보조 화면. 단서가 없는 사물도 섞어 둔다. 용의자의 겉모습 살펴보기는 4명 모두에게 둔다
- 최종 추리에 근거(가설·카드)를 첨부하고, 보고서에 추리 과정이 남는다

## 세션 3 — 새 설계 검증 (Codex, 스크린샷 7장)

| 우선순위 | Codex 지적 | 처리 |
|---|---|---|
| P0 | A의 가방 단서(무료 조사)만으로 경위까지 확정되고 바로 자백이 나와, 질문을 아끼려면 대화·비교를 건너뛰는 것이 최적 전략이 된다 | **시나리오 문제라 팀이 결정할 일로 남김.** UI에서 강제하지 않는다. 제안: 가방 내용에서 휴대폰 알림을 빼고 "도시락통이 없다"만 남긴 뒤, 자백 조건을 "가방 + D의 진술 인용"처럼 대화와 연결한다 |

| P1 | 승리 조건인 "사용 수"가 폰에서 숨겨져 있고, 집중 심문이 보너스처럼 보인다 | 상단에 "사용 n회 · 적을수록 유리"를 항상 표시. 집중 심문 버튼에 "+5 · 순위 합산", 입력부에 "조사·카드 정리는 무료 · 묻기만 1회" |
| P1 | 폰에서 답변 공간이 부족하고, 시간표 카드를 읽거나 옮길 수 없다 | 폰 헤더를 한 줄로 줄이고 버튼은 아이콘만 남김. 입력창은 접혀 있다가 포커스 시 펼침. 시간표 카드를 누르면 전문·시간 수정·인용이 가능하고, 미지정 카드도 시간표 탭에서 배치 |
| P2 | 빨간 "어긋남" 표시가 시스템이 확정한 것처럼 보인다 | "내 모순 가설 · 게임이 확인해 준 것은 아님", 점선 테두리, "어긋나는 것 같다", 메모 안내를 "어떤 전제에서 어긋나나요?"로 변경 |

## 다시 방향 전환 (2026-11-18 오후)

팀 피드백 (대화 중심 시제품에 대해):
1. 게임이 아니라 웹앱 같다
2. 분위기·그림체가 별로다
3. 대화 화면이 채팅방 같다
4. 현장에서 증거가 있을 만한 곳의 표식(?, 조사 대상 목록)이 다 보인다

결정: 코드를 고치기 전에 레퍼런스를 정하고 **정적 이미지 초안 4개**로 방향을 고른다. 이미지는 Codex 이미지 생성으로 만든다. 브리프는 `docs/design/drafts/briefs/`.

## 세션 4 — 레퍼런스와 방향 검토 (Codex)

| Codex 의견 | 결정 |

## 화면 조정 (2026-11-18 오후 4시)

팀 피드백과 처리:
- **대사창이 너무 커서 장면을 가린다** → 대사창 높이를 약 절반으로 줄였다. 화면 너비의 76%만 쓰고 가운데에 둔다. 초상과 글자도 작게 했다.
- **화면을 좌우로 더 넓게** → 장면 비율을 3:2에서 **16:9**로 바꿨다. 배경 위아래(천장·바닥)를 잘랐고 좌표도 다시 맞췄다. 16:10 모니터(1440×900)에서는 위아래에 얇은 띠가 생긴다.
- **팀은 남자 3명, 여자 1명** → 임시 인물 C를 남자(안경, 남보라 머리)로 다시 그렸다. 지금은 A만 여자다. 실제 누가 누구인지는 캐릭터 시트에서 정한다.
- **실제 강의실** → 빔프로젝터와 내려온 스크린을 넣고, 화이트보드·칠판·벽시계는 뺐다. 강사님 자리는 오른쪽 앞의 일반 책상이다. 아직 사진 없이 설명만으로 그린 그림이다.
- 같은 시간대에 동사 버튼 줄이 빠지고(사람을 누르면 바로 질문, 물건을 누르면 조사) 대화 기록이 수첩 2쪽으로 옮겨졌다. 이 변경은 그대로 두고 그 위에 작업했다.

- **계절·시간대:** 가을 노을에서 **초겨울 낮**으로 바꿨다. 두 배경을 같은 구도로 다시 그렸다: 앙상한 가로수와 얇은 눈, 파란 겨울 하늘, 흰 낮빛, 차분한 회청색 바닥. 구도가 같아서 클릭 좌표는 그대로다. 창문 관찰문도 겨울로 바꿨다.
- **글꼴 버그:** 픽셀 글꼴(갈무리)이 처음부터 **전혀 적용되지 않고** 있었다. 브라우저 기본 Times와 시스템 한글 글꼴로 보였다.
  - 원인: 글꼴 변수를 `<body>`에 달았는데 CSS 토큰은 `:root`(html)에서 참조했다.
  - 처리: 변수를 `<html>`로 옮겨 게임 전체가 갈무리로 보이게 했다.
- **수첩 글자 선명도:** 갈무리는 픽셀 격자 크기(갈무리14는 15·30px, 갈무리11은 12px)에서만 선명하다. 그 사이 크기(13·14·16·22px)에서는 흐리고, "1" 같은 가는 획이 사라진다.
  - 수첩과 보고서 종이 위 글자를 격자 크기로만 쓰도록 바꿨다.
  - 자동 검사 결과, 수첩 4쪽 전체에서 격자 밖 크기는 0개다.

## 싱크대 제거 · 최종 추리 '이유' 제거 (2026-11-18)

- 실제 휴게실에는 싱크대가 없다. 휴게실 배경에서 싱크대와 파란 통을 지우고(나머지는 그대로) 싱크대 클릭 영역과 예시 단서도 뺐다.

## 세션 8 — 용의자 4명을 실제 사진 기반으로 교체 (2026-11-25~26, Codex)

- 팀원 사진을 받아 봉경·건희·원·윤찬 그림을 다시 그렸다. **사진은 저장소에 넣지 않았다**(팀 공유 폴더에만 보관). 초록 배경 원본도 용량 때문에 팀 공유 폴더에만 둔다.
- 화풍·크기·표정별 포즈는 기존 그대로, 얼굴·머리·옷만 사진에 맞췄다. 학원은 자율복장이라 교복 대신 각자 사진 속 스타일의 평상복(겨울)으로 바꿨다.

| 인물 | 외모 | 옷 |
|---|---|---|
| 김봉경 | 검은 머리 낮은 묶음, 잔머리, 둥근 얼굴, 진주 귀걸이 | 크림 V넥 니트 + 흰 셔츠 깃 + 검은 와이드 팬츠 |
| 황건희 | 거의 검은 부스스한 머리, 무거운 앞머리, 귀 보임 | 검은 반팔 니트 헨리 + 검은 슬랙스 |
| 전원 | 짧고 단정한 검은 머리, 눈썹 위 일자 앞머리, 갸름한 얼굴, 안경 없음 | 흰 오버핏 맨투맨 + 하늘색 와이드 나일론 팬츠 |
| 황윤찬 | 곧은 검은 머리, 눈까지 오는 앞머리, 귀를 덮는 옆머리 | 열린 검은 집업 재킷 + 남색 후드 + 연청 와이드 진 |

- 만든 방법:
  1. 사람마다 평온 상반신 1장을 사진 + 기존 그림을 참조로 그려 확정했다.
  2. 그 그림을 기준으로 나머지 3표정과 초상 시트(2×2)를 그렸다.
  3. Codex 검토 → 지적받은 얼굴형(사진보다 갸름·눈이 큼)을 사람마다 한 번씩 더 고쳤다. 옷은 Codex 검토 "통과", 봉경 바지가 치마처럼 보인다는 지적만 반영했다.
  4. 교실 배경은 클릭 좌표가 어긋나지 않도록 사람 주변만 잘라 고치고 바뀐 픽셀만 되붙였다(주변 밖 픽셀 변화 0). 다리처럼 경계에 걸친 곳은 AI 대신 색만 직접 바꿨다.
- 배경 이음매 정리: AI가 사람 주변의 모니터·키보드·바닥까지 살짝 옮겨 그려 이음매가 생겼다. 사물은 옷 바꾸기 전 배경에서 되살리고, 원의 앉은 모습은 깨끗한 배경 위에서 옷 색만 바꾸고 머리만 붙였다. 패치끼리 겹쳐 봉경 팔이 옛 그림으로 덮였던 부분도 바로잡았다.
- 사용자 지시로 반영한 것: 원은 안경을 쓰지 않는다. 원은 세 번째 사진(정면)을 기준으로 다시 그렸다. AI가 넣은 볼의 점은 지웠다.
- 덤: 예전 봉경·건희·윤찬 '화남' 초상은 시트 전체가 한 칸에 줄어 들어간 잘못 잘린 파일이었는데 이번에 모두 바로잡혔다. 윤찬 입가의 옛 시나리오용 소스 자국도 뺐다.
