# AI 추리게임 시나리오 작성 규칙과 양식

팀원 한 명이 사건 한 편을 구상할 때 씁니다. 1부의 규칙을 읽고, 2부의 양식을 채운 뒤, 3부의 점검표로 스스로 확인합니다.

**자기가 쓴 사건은 직접 플레이할 수 없습니다.** 정답을 알기 때문입니다. 네 명이 한 편씩 쓰면 각자 나머지 세 편을 플레이할 수 있습니다. 완성 전까지 다른 팀원에게 내용을 보여 주지 마세요.

---

# 1부. 판단 규칙

## 1. 게임이 정답을 판정하는 방식

플레이어는 마지막에 세 가지를 선택지에서 고릅니다. 시나리오는 이 세 가지의 정답을 정확히 하나씩 가져야 합니다.

| 고르는 것 | 선택지 | 판정 |
|---|---|---|
| 누가 | 용의자 4명 또는 "아무도 아님" | 맞혀야 정답 |
| 어떤 경위로 | 시나리오가 주는 4~5개 | 맞혀야 정답 |
| 결정적 증거 | 플레이어가 찾은 단서 중 1개 | 동점일 때 순위를 가름 |

승자는 정답자 중 질문을 가장 적게 쓴 사람입니다. 따라서 시나리오는 "잘 추리하면 적은 질문으로 풀리고, 찍어서는 맞히기 어렵게" 만들어야 합니다.

## 2. 사건 규칙

| 번호 | 규칙 |
|---|---|
| 사건-1 | 배경은 학원과 교실, 소재는 가볍고 웃긴 일상 사건이다. 다치거나 큰돈이 오가는 사건은 쓰지 않는다. |
| 사건-2 | 원인은 고의, 실수, 우연, 자연 고장 중 하나다. 자연 고장이나 우연이면 "누가"의 정답은 "아무도 아님"이다. |
| 사건-3 | 사건이 일어난 시간대는 1시간 안팎으로 잡는다. 길면 시간표가 복잡해져 20분 안에 풀 수 없다. |
| 사건-4 | 모든 사실에 들어맞는 설명은 정답 하나뿐이어야 한다. |
| 사건-5 | 반전이 하나 있어야 한다. 가장 먼저 의심받는 사람이 범인이 아니어야 한다. |

## 3. 용의자 규칙

AI는 시트에 적힌 대로만 행동합니다. 아래 규칙을 지켜야 AI가 흔들리지 않습니다.

| 번호 | 규칙 |
|---|---|
| 용의자-1 | 용의자는 정확히 4명이다. |
| 용의자-2 | 각 용의자는 자기가 직접 하고, 보고, 들은 것만 안다. 결백한 용의자는 진상을 모른다. |
| 용의자-3 | 거짓말은 "숨기는 것"으로 적은 내용에 대해서만 한다. 그 밖의 질문에는 사실대로 답한다. |
| 용의자-4 | 숨기는 것에는 반드시 이유가 있어야 한다. (부끄러워서, 친구를 감싸려고, 혼날까 봐) |
| 용의자-5 | 숨기는 것은 특정 단서 하나를 내밀었을 때만 털어놓는다. 말로 조르는 것만으로는 털어놓지 않는다. |
| 용의자-6 | 무언가를 숨기는 용의자는 2~3명이다. 최소 1명은 숨기는 것 없이 사실만 말한다. |
| 용의자-7 | 범인이 아닌데 수상해 보이는 미끼 용의자가 최소 1명 있어야 한다. |
| 용의자-8 | 숨기는 것이 없는 용의자도 추리에 필요한 증언을 하나 이상 갖고 있어야 한다. 쓸모없는 용의자는 없다. |

## 4. 단서 규칙

단서는 교실 화면에서 사물을 눌렀을 때 나오는 글입니다. AI가 쓰지 않고 작성자가 미리 씁니다.

| 번호 | 규칙 |
|---|---|
| 단서-1 | 단서는 5~8개다. |
| 단서-2 | 단서에는 눈에 보이는 사실만 쓴다. 해석을 쓰지 않는다. ("포장지가 떨어져 있다"는 되고 "누군가 몰래 먹은 것 같다"는 안 된다) |
| 단서-3 | 그림으로 그릴 수 있는 사물이나 흔적이어야 한다. |
| 단서-4 | 결정적 증거는 정확히 1개다. 이것 없이는 정답을 확신할 수 없어야 한다. |
| 단서-5 | 미끼 용의자를 수상하게 만드는 단서가 1~2개 있고, 그 의심을 풀어 주는 단서도 반드시 있다. |
| 단서-6 | 용의자가 숨기는 것마다 그것을 털어놓게 하는 단서가 하나씩 짝지어져 있다. |
| 단서-7 | 단서만 모아서는 정답이 나오지 않아야 한다. 증언이 최소 2개 더 필요해야 한다. |

## 5. 풀이 규칙

| 번호 | 규칙 |
|---|---|
| 풀이-1 | 용의자 한 명만 취조해서는 풀 수 없다. 최소 두 명의 말을 맞춰 봐야 한다. |
| 풀이-2 | 정답에 필요한 정보는 모두 단서나 증언으로 얻을 수 있다. 플레이어가 짐작해야만 하는 빈칸이 없다. |
| 풀이-3 | 가장 짧은 풀이는 질문 6~10개다. 5개 이하면 너무 쉽고, 15개 이상이면 20개 안에 못 푼다. |
| 풀이-4 | 오답 용의자 3명과 오답 경위 각각에 대해, 그것을 배제하는 단서나 증언이 있어야 한다. |
| 풀이-5 | 오답 경위는 모두 그럴듯해야 한다. 누가 봐도 아닌 선택지는 넣지 않는다. |

## 6. 배려 규칙

용의자가 실제 팀원을 모델로 하므로 지켜야 합니다.

| 번호 | 규칙 |
|---|---|
| 배려-1 | 팀원을 고의로 나쁜 짓을 한 사람으로 설정하려면 본인에게 먼저 동의를 받는다. 사건 내용을 밝히지 않고 "네 캐릭터가 범인 역할이어도 괜찮은지"만 묻는다. |
| 배려-2 | 외모, 성적, 가정사, 연애, 금전 사정을 소재로 쓰지 않는다. |
| 배려-3 | 숨기는 이유는 웃고 넘길 수 있는 것으로 한다. |
| 배려-4 | 선생님이나 다른 수강생 등 팀원이 아닌 실존 인물은 이름 없이 직함으로만 등장시킨다. |

# 3부. 자가 점검표

제출 전에 하나씩 확인하고 `x`를 넣습니다. 하나라도 비면 고쳐서 다시 확인합니다.

## 사건

- [ ] 학원 배경의 가벼운 일상 사건이다. (사건-1)
- [ ] 누가, 경위, 결정적 증거의 정답이 각각 하나다. (사건-4)
- [ ] 가장 먼저 의심받는 사람이 범인이 아니다. (사건-5)

## 용의자

- [ ] 각 용의자의 "직접 보거나 들은 것"이 시간표와 맞는다. 그 시각 그 자리에 없던 사람이 본 것은 없다. (용의자-2)
- [ ] 결백한 용의자의 표 어디에도 진상이 적혀 있지 않다. (용의자-2)
- [ ] 숨기는 것마다 이유와 털어놓게 하는 단서가 짝지어져 있다. (용의자-4, 5)
- [ ] 숨기는 용의자가 2~3명이고, 사실만 말하는 용의자가 1명 이상이다. (용의자-6)
- [ ] 네 명 모두 "추리에 꼭 필요한 증언"이 채워져 있다. (용의자-8)

## 단서

- [ ] 단서 글에 해석이나 추측이 없다. (단서-2)
- [ ] 결정적 증거가 정확히 1개다. (단서-4)
- [ ] 미끼 단서마다 그것을 해소하는 단서가 있다. (단서-5)

## 풀이

- [ ] **한 명 테스트**: 용의자 한 명의 표와 단서만 보고는 정답을 확신할 수 없다. 네 명 각각에 대해 확인했다. (풀이-1)
- [ ] **조사만 테스트**: 단서 표만 보고는 정답을 확신할 수 없다. (단서-7)
- [ ] **빈칸 테스트**: 최단 풀이 경로의 "알게 되는 것"만 이으면 진상이 완성된다. (풀이-2)
- [ ] 최단 풀이 경로의 질문 수가 6~10개다. (풀이-3)
- [ ] 오답 배제표에 빈칸이 없다. (풀이-4)
- [ ] 오답 경위가 모두 그럴듯하다. (풀이-5)

## 배려

- [ ] 범인이나 난처한 역할을 맡은 팀원에게 동의를 받았다. (배려-1)
- [ ] 금지 소재를 쓰지 않았다. (배려-2)

# 4부. 팀 심사 기준

여러 편 중 먼저 만들 사건을 고르거나, 서로의 시나리오를 검토할 때 씁니다. 검토자는 그 사건을 플레이할 수 없게 되므로, 검토자는 사건당 한 명만 둡니다.

| 기준 | 5점 | 1점 |
|---|---|---|
| 풀이 가능성 | 자가 점검표를 모두 통과하고 최단 경로가 6~10개 | 풀 수 없거나 찍어야 한다 |
| 반전 | 진상을 알았을 때 "아!" 소리가 난다 | 처음 의심한 사람이 그대로 범인이다 |
| 웃음 | 숨기는 이유와 진상이 웃기다 | 밋밋하거나 누군가 불쾌할 수 있다 |
| 용의자 활용 | 네 명 모두에게 물어볼 이유가 있다 | 한두 명만 물어도 된다 |
| 제작 난이도 | 기존 교실 배경에 사물 몇 개만 추가하면 된다 | 새 배경이나 그림이 많이 필요하다 |

합계 25점 만점. 풀이 가능성이 3점 이하면 다른 점수와 관계없이 고쳐서 다시 냅니다.
